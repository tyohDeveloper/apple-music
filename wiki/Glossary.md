# Glossary

| Term | Meaning |
|---|---|
| Album | The release its artists intended |
| Apple mirror | The application's copy of what Apple Music returned at the last import |
| Change outbox | Proposed changes to Apple Music awaiting approval, and the record of applied ones |
| Credit | A performer's role on a recording or album, with the name printed |
| Developer token | A signed token identifying the application to Apple |
| Edition | One issued form of an album, such as a deluxe edition |
| Inclusion | How an edition track relates to the intended album: core, demo, live and so on |
| Intended track list | The album's tracks as originally released |
| Library | The datastore for one Apple ID |
| Music User Token | Apple's token granting access to one user's library |
| Performer | Anyone credited: person, group, duo, orchestra, choir, ensemble |
| Recording | One captured performance |
| Relation | A standing link between performers, such as membership |
