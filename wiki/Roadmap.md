# Roadmap

The authoritative plan, with exit criteria and open questions, is [docs/PLAN.md](https://github.com/tyohDeveloper/apple-music/blob/main/docs/PLAN.md).

| Phase | Delivers |
|---|---|
| 0 — Plan | Requirements, decisions, domain model, standards adoption, this wiki |
| 1 — Foundation | Server, database roles and migrations, sign-in, client shell, checks and CI |
| 2 — Curated catalog | Performers, names, relations, albums, editions, recordings, credits, genres; export |
| 3 — Apple Music import | Connecting a library; imports with credit parsing, edition grouping and track classification |
| 4 — Cleanup workflows | Review of extras, intended track lists, merges, names and relations |
| 5 — Apple Music changes | Approved playlists, ratings, favorites and library additions |
| 6 — Other databases | MusicBrainz lookups and identifiers |
| 7 — Depth | Works and compositions, edit history, Sign in with Apple, more users |
| 8+ — Reach | Other streaming services; native apps |
