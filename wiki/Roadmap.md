# Roadmap

The authoritative plan, with exit criteria and open questions, is [docs/PLAN.md](https://github.com/tyohDeveloper/apple-music/blob/main/docs/PLAN.md).

| Phase | Delivers | Status |
|---|---|---|
| 0 — Plan | Requirements, decisions, domain model, standards adoption, this wiki | Done |
| 1 — Foundation | Server, database roles and migrations, sign-in, client shell, checks and CI | Done, version 0.1.0.0 |
| 2 — Curated catalog | Performers, names, relations, albums, editions, recordings, credits, genres, identifiers; export | Done, version 0.2.0.0 |
| 3 — Apple Music import | Connecting a library; imports with credit parsing, edition grouping and track classification | Next |
| 4 — Cleanup workflows | Review of extras, intended track lists, merges, names and relations | Planned |
| 5 — Apple Music changes | Approved playlists, ratings, favorites and library additions | Planned |
| 6 — Other databases | MusicBrainz lookups that suggest matches and fill in identifiers | Planned |
| 7 — Depth | Works and compositions, edit history, Sign in with Apple, more users | Planned |
| 8+ — Reach | Other streaming services; native apps | Planned |
